# AniKot 2.1.3 — Accuracy v3

VK-бот для поиска аниме и дунхуа по кадру, фото и названию. Версия рассчитана на BotHost.ru, запускается через `main.py`, собственного Dockerfile не требует.

## Поисковые режимы

- **AniKot** — `gpt-5.4-nano`.
- **AniKot Pro** — `gpt-5.4-mini`.
- **AniKot Pro+** — `gpt-5.5`.
- Внешний каталог для перепроверки не используется: выбранная модель анализирует изображение напрямую.
- Минимальные пороги по умолчанию: 55% / 65% / 75%.
- Администраторы из `ADMIN_IDS` имеют безлимит всех трёх типов запросов.

## Accuracy v3 — улучшенное распознавание кадров

Версия 2.1.3 усиливает именно определение аниме по изображению.

Первый проход теперь работает как визуальный идентификатор, а не как обычное описание картинки. Модель обязана учитывать:

- лицо, волосы, глаза и характерные детали персонажа;
- одежду, форму, эмблемы, украшения, оружие и необычные предметы;
- окружение, архитектуру, эпоху, школу/форму, магию и технологии;
- японский, китайский, английский и русский текст на кадре;
- стиль анимации только как вспомогательный сигнал;
- возможную зеркальность, обрезку, фильтры, AMV-эффекты, субтитры и интерфейс соцсетей;
- путаницу между сезонами, спин-оффами, ремейками и похожими персонажами;
- отрицательные признаки: если важная деталь противоречит кандидату, его вероятность должна снижаться.

Модель внутренне сравнивает минимум пять кандидатов и возвращает до четырёх реальных альтернатив. Confidence теперь калибруется строже: 90%+ разрешается только при нескольких согласующихся признаках или действительно уникальном визуальном якоре.

### Независимый verifier

Для неоднозначных кадров автоматически запускается второй независимый анализ тем же тарифным уровнем. Он специально пытается опровергнуть результат первого прохода и может выбрать другой тайтл, если визуальные признаки не сходятся.

Verifier включается, если:

- уверенность первого прохода ниже заданного порога;
- два кандидата слишком близки;
- нет уникального визуального якоря;
- модель сама пометила результат как требующий проверки;
- классификация «аниме / не аниме» выглядит пограничной.

Это повышает точность сложных кадров, но на неоднозначных изображениях может потребоваться второй запрос к модели со стороны сервера. Пользователь всё равно платит один запрос AniKot.

Настройки:

```env
AIAI_VISION_VERIFY=true
AIAI_VISION_VERIFY_BELOW=0.88
AIAI_VISION_VERIFY_MARGIN=0.12
AIAI_VISION_VERIFY_UNANCHORED=true
AIAI_VISION_VERIFIER_REASONING=medium
```

Чтобы полностью отключить второй проход:

```env
AIAI_VISION_VERIFY=false
```

Старые результаты vision-кэша версии 2.1.2 автоматически не используются: Accuracy v3 сохраняет обязательный маркер новой версии анализа, поэтому кадр пересчитывается и уже затем снова кэшируется.

Под результатом только inline-кнопка `Назад`.

## Интерфейс поиска

Все кнопки inline и прикрепляются к конкретному сообщению. Постоянной клавиатуры под строкой ввода нет.

Во время поиска показывается временное сообщение:

```text
🔍 AniKot анализирует кадр...
```

Под ним кнопка `Отмена` без символов. После завершения поиска временное сообщение автоматически удаляется.

## Поддержка

Команда `support`, `/support`, `поддержка` или deep-link с `ref=support` открывает поддержку.

Сначала пользователь выбирает тему:

- **Техническая проблема** — сразу живому администратору.
- **Оплата** — сразу живому администратору.
- **Поиск и режимы** — AI-поддержка.
- **Аккаунт и запросы** — AI-поддержка.
- **Бонусы и рефералы** — AI-поддержка.
- **Функции AniKot** — AI-поддержка.
- **Другое** — AI-поддержка.

AI первой линии по умолчанию использует `qwen3-32b` через AIAI.BY. Ему передаются только безопасные данные о функционале AniKot и текущие данные самого пользователя. API-ключи, токены, ID администраторов и другие секреты в prompt не передаются.

Если вопрос фактически относится к оплате или технической неисправности, он передаётся администратору даже при ошибочно выбранной теме. AI также эскалирует вопрос, если не знает точного ответа или требуется ручная проверка.

Настройки:

```env
SUPPORT_ADMIN_IDS=
SUPPORT_AI_MODEL=qwen3-32b
SUPPORT_AI_MAX_TOKENS=700
SUPPORT_AI_TIMEOUT=90
SUPPORT_AI_HISTORY_LIMIT=6
SUPPORT_AI_HOURLY_LIMIT=20
```

Все `ADMIN_IDS` автоматически входят в список операторов поддержки.

## Регистрация и бонусы

- Регистрация: **+1 обычный запрос AniKot**.
- Подписка на сообщество: **+2 обычных запроса AniKot** один раз.
- За приглашённого друга: **+3 запроса AniKot Pro** после 3-дневной проверки нового пользователя.
- Каждому пользователю создаётся индивидуальная ссылка `https://vk.me/<community>?ref=anikot_<token>`.

## Страйки и защита

Если пользователь получил бонус за подписку и затем отписался, начисляется страйк. **3 страйка = блокировка аккаунта AniKot**.

Явно не-аниме изображение не списывает запрос, но даёт предупреждение. По умолчанию после 5 предупреждений доступ блокируется на 7 дней. Accuracy v3 дополнительно перепроверяет пограничные случаи перед тем, как считать изображение не-аниме.

## Контент 18+

Если обычный AniKot или Pro распознаёт adult-контент, запрос не должен обрабатываться в обычном режиме и пользователю предлагается Pro+. Для adult-поиска Pro+ требуется подтверждение 18+.
