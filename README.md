# AniKot 2.3.1 — Hybrid Search + High Load

VK-бот для поиска аниме и дунхуа по кадру, фото и названию. Версия рассчитана на BotHost.ru и запускается через `main.py`.

## Поиск

Текущая архитектура:

```text
AniKot
→ Qwen3.5 Flash

AniKot Pro
→ AnimeTrace
→ DeepSeek V4 Flash проверяет и нормализует кандидатов

AniKot Pro+
→ AnimeTrace
+
Kimi K2.6 независимо анализирует исходный кадр
→ Kimi сверяет оба результата
```

- **AniKot** — `qwen3.5-flash`
- **AniKot Pro** — AnimeTrace + `deepseek-v4-flash`
- **AniKot Pro+** — AnimeTrace + `kimi-k2.6`
- Минимальные пороги по умолчанию: 55% / 65% / 75%
- Администраторы из `ADMIN_IDS` имеют безлимит поисков
- Vision-кэш хранит результаты 30 дней
- Одновременно допускается ограниченное число ожидающих поисков (`MAX_PENDING_SEARCHES`)

На 17.09.2026 рабочий default Pro — `deepseek-v4-flash`. `AIAI_PRO_MODEL` остаётся настраиваемым через окружение, поэтому другую совместимую модель можно включить без изменения архитектуры.

## Hybrid Accuracy v4

### Обычный AniKot

Обычный поиск использует мультимодальную `Qwen3.5 Flash` через AIAI.BY. Модель получает исходное изображение и сама определяет тайтл, персонажа и метаданные.

Старое значение `AIAI_ANIKOT_MODEL=gpt-5.4-nano` автоматически считается прежним default и мигрирует на `qwen3.5-flash`.

### AniKot Pro

Для изображения нормальный путь:

1. AnimeTrace получает исходный кадр и возвращает кандидатов произведений/персонажей.
2. DeepSeek получает структурированные кандидаты AnimeTrace, проверяет их согласованность, алиасы и переводы.
3. Если AnimeTrace помечает боксы как `not_confident`, итоговая уверенность ограничивается консервативно.
4. При временной недоступности AnimeTrace/DeepSeek используется fallback, чтобы поиск не падал целиком.

Для текстового поиска AnimeTrace не используется: текстовый Pro идёт непосредственно в DeepSeek.

### AniKot Pro+

AnimeTrace и Kimi K2.6 запускаются независимо по одному исходному кадру. После этого Kimi сверяет свой vision-результат с кандидатами AnimeTrace и формирует финальный ответ.

Если AnimeTrace временно недоступен, Pro+ продолжает работать через независимый Kimi vision-поиск.

### AnimeTrace

AniKot не фиксирует конкретную модель AnimeTrace. При запуске клиент запрашивает `/v1/model/list` и использует доступную/default модель. Поиск идёт через `/v1/search` с `is_multi=1` и `ai_detect=1`.

```env
ANIMETRACE_ENABLED=true
ANIMETRACE_BASE_URL=https://api.animetrace.com
ANIMETRACE_MODEL=
ANIMETRACE_TIMEOUT=15
ANIMETRACE_MAX_CONCURRENCY=2
ANIMETRACE_MIN_INTERVAL_MS=500
```

Клиент обрабатывает 429/503 и известные коды AnimeTrace, включая `17702`, `17704`, `17706`, `17728` и `17731`. На лимитах/перегрузке открывается временный circuit breaker.

## Исправление интерфейса 2.3.1

Встроенная поддержка полностью удалена из AniKot. Ранее её обработчик принудительно ставился первым в очереди VK-хендлеров и при сохранённой support-сессии мог перехватывать обычные текстовые сообщения и нажатия на inline-клавиатуру. Из-за этого кнопки вроде `Назад`, `Купить запросы`, `Профиль` и другие могли визуально отправляться пользователем, но не доходить до основного роутера AniKot.

С версии 2.3.1 у AniKot снова один основной message-router для пользовательского интерфейса. Поддержка должна работать отдельным ботом и не подключается к runtime AniKot.

## High Load

Перед основными обработчиками работает middleware, который:

- ограничивает число одновременно выполняющихся обработчиков;
- ограничивает частоту сообщений от одного пользователя;
- во время глобальной перегрузки отбрасывает лишние события до обращения к SQLite и внешним API;
- ограничивает количество предупреждений о перегрузке;
- не применяет пользовательский rate-limit к администраторам.

```env
MAX_INFLIGHT_MESSAGES=120
MESSAGE_RATE_BURST=12
MESSAGE_RATE_WINDOW_SECONDS=10
RATE_LIMIT_WARNING_INTERVAL=8
OVERLOAD_WARNINGS_PER_SECOND=5
```

SQLite работает через небольшой пул постоянных соединений с WAL:

```env
DB_POOL_SIZE=4
```

Распознавание через AIAI.BY ограничено общим semaphore:

```env
AIAI_MAX_CONCURRENCY=3
```

AnimeTrace имеет собственный лимит:

```env
ANIMETRACE_MAX_CONCURRENCY=2
ANIMETRACE_MIN_INTERVAL_MS=500
```

## Интерфейс поиска

Во время поиска показывается временное сообщение:

```text
🔍 AniKot анализирует кадр...
```

Кнопка отмены называется `Отмена`. После завершения поиска временное сообщение удаляется.

Формат результата:

```text
🎬 Название: Внук мудреца
👤 Персонаж: Сицилия фон Клод
🌍 Страна: Япония
📅 Год: 2019
📺 Количество эпизодов: 12
🎯 Уверенность: 95%
```

## Регистрация и бонусы

- регистрация: `+1` обычный AniKot;
- подписка на сообщество: `+2` обычных AniKot один раз;
- приглашённый друг: `+3` AniKot Pro после 3-дневной проверки;
- 3 страйка за отписку после получения бонуса блокируют аккаунт;
- явно не-аниме изображение не списывает поисковый запрос, но может дать предупреждение.
