# AniKot 2.1.2 — Russian Accuracy

VK-бот для поиска аниме и дунхуа по кадру, фото и названию. Версия рассчитана на BotHost.ru, запускается через `main.py`, собственного Dockerfile не требует.

## Поисковые режимы

- **AniKot** — `gpt-5.4-nano`.
- **AniKot Pro** — `gpt-5.4-mini`.
- **AniKot Pro+** — `gpt-5.5`.
- В проекте больше нет внешнего каталога для перепроверки результатов: ответ формируется выбранной моделью напрямую.
- Минимальные пороги по умолчанию: 55% / 65% / 75%.
- Администраторы из `ADMIN_IDS` имеют безлимит всех трёх типов запросов.

## Поддержка

Команда `support`, `/support`, `поддержка` или deep-link с `ref=support` открывает поддержку.

Сначала пользователь выбирает тему:

- **Техническая проблема** — сразу живому администратору.
- **Оплата** — сразу живому администратору.
- **Поиск и режимы** — AI-поддержка.
- **Аккаунт и запросы** — AI-поддержка.
- **Бонусы и рефералы** — AI-поддержка.
- **Функции AniKot** — AI-поддержка.
- **Другое** — AI-поддержка.

AI первой линии по умолчанию использует `qwen3-32b` через AIAI.BY. Ему передаются только безопасные данные о функционале AniKot и текущие данные самого пользователя: балансы, режим поиска, бонус за подписку, страйки и предупреждения. API-ключи, токены, ID администраторов и другие секреты в prompt не передаются.

Если вопрос фактически относится к оплате или технической неисправности, он передаётся администратору даже при ошибочно выбранной теме. AI также эскалирует вопрос, если не знает точного ответа или требуется ручная проверка.

Настройки:

```env
SUPPORT_ADMIN_IDS=
SUPPORT_AI_MODEL=qwen3-32b
SUPPORT_AI_MAX_TOKENS=700
SUPPORT_AI_TIMEOUT=90
SUPPORT_AI_HISTORY_LIMIT=6
SUPPORT_AI_HOURLY_LIMIT=20
```

Все `ADMIN_IDS` автоматически входят в список операторов поддержки. `SUPPORT_ADMIN_IDS` предназначен для дополнительных операторов без полного админ-доступа.

Когда обращение передано человеку, оператор получает уведомление с кнопкой `Ответить`. После её нажатия его обычные сообщения уходят только выбранному пользователю. После каждого ответа бот пишет `Сообщение успешно отправлено` и показывает кнопки `Ожидать ответ` / `Закрыть чат`.

История обращений и AI-диалога хранится в SQLite. AI-история ограничена и очищается при закрытии AI-поддержки/смене новой AI-темы.

## Формат результата

```text
🎬 Название: Внук мудреца
👤 Персонаж: Сицилия фон Клод
🌍 Страна: Япония
📅 Год: 2019
📺 Количество эпизодов: 12
🎯 Уверенность: 95%
```

Под результатом только inline-кнопка `Назад`.

## Интерфейс поиска

Все кнопки inline и прикрепляются к конкретному сообщению. Постоянной клавиатуры под строкой ввода нет.

Во время поиска показывается временное сообщение:

```text
🔍 AniKot анализирует кадр...
```

Под ним кнопка `Отмена` без символов. После завершения поиска временное сообщение автоматически удаляется.

## Главная

```text
Режим поиска
Профиль | Купить запросы

```

После получения бонуса кнопка `Бонус за подписку` исчезает.

## Регистрация и бонусы

- Регистрация: **+1 обычный запрос AniKot**.
- Подписка на сообщество: **+2 обычных запроса AniKot** один раз.
- За приглашённого друга: **+3 запроса AniKot Pro** после 3-дневной проверки нового пользователя.
- Каждому пользователю создаётся индивидуальная ссылка `https://vk.me/<community>?ref=anikot_<token>`.
- Для постоянной базы рекомендуется `VK_REFERRAL_BASE_URL=https://vk.me/club<ID>`.

## Страйки и защита

Если пользователь получил бонус за подписку и затем отписался, начисляется страйк. **3 страйка = блокировка аккаунта AniKot**.

Явно не-аниме изображение не списывает запрос, но даёт предупреждение. По умолчанию после 5 предупреждений доступ блокируется на 7 дней.

## Контент 18+

Если обычный AniKot или Pro распознаёт adult-контент, запрос не должен обрабатываться в обычном режиме и пользователю предлагается Pro+. Для adult-поиска Pro+ требуется подтверждение 18+.

## BotHost

- Главный файл: `main.py`
- Порт в панели: `3000`
- Dockerfile: выключен
- `WEB_HOST=0.0.0.0`
- `PORT` вручную не создавать — BotHost передаёт его сам.

https://anikot.bothost.tech/health
