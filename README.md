# AniKot 2.2.0 — High Load + Accuracy v3

VK-бот для поиска аниме и дунхуа по кадру, фото и названию. Версия рассчитана на BotHost.ru и запускается через `main.py`.

## Поиск

- **AniKot** — `gpt-5.4-nano`
- **AniKot Pro** — `gpt-5.4-mini`
- **AniKot Pro+** — `kimi-k2.6`
- Минимальные пороги по умолчанию: 55% / 65% / 75%
- Администраторы из `ADMIN_IDS` имеют безлимит поисков
- Vision-кэш хранит результаты 30 дней
- Одновременно допускается ограниченное число ожидающих поисков (`MAX_PENDING_SEARCHES`), поэтому резкий наплыв пользователей не создаёт неограниченное число тяжёлых задач

## Accuracy v3

Распознавание кадра использует строгий визуальный анализ: лицо, волосы, глаза, одежду, эмблемы, оружие, окружение, архитектуру, видимый текст, особенности франшизы и отрицательные признаки.

Модель внутренне сравнивает несколько кандидатов и при неоднозначном результате запускает независимый verifier тем же тарифным уровнем. Verifier может отвергнуть первый ответ и выбрать другой тайтл.

```env
AIAI_VISION_VERIFY=true
AIAI_VISION_VERIFY_BELOW=0.88
AIAI_VISION_VERIFY_MARGIN=0.12
AIAI_VISION_VERIFY_UNANCHORED=true
AIAI_VISION_VERIFIER_REASONING=medium
```

## High Load 2.2

Версия 2.2 добавляет защиту от резких всплесков нагрузки.

### Ограничение входящих сообщений

Перед основными обработчиками работает middleware:

- ограничивает число одновременно выполняющихся обработчиков;
- ограничивает частоту сообщений от одного пользователя;
- во время глобальной перегрузки отбрасывает лишние события до обращения к SQLite и внешним API;
- ограничивает количество предупреждений о перегрузке, чтобы сами предупреждения не создали новый всплеск запросов;
- администраторы не ограничиваются пользовательским rate-limit.

Настройки:

```env
MAX_INFLIGHT_MESSAGES=120
MESSAGE_RATE_BURST=12
MESSAGE_RATE_WINDOW_SECONDS=10
RATE_LIMIT_WARNING_INTERVAL=8
OVERLOAD_WARNINGS_PER_SECOND=5
```

### SQLite pool

Раньше большинство операций открывали новое SQLite-соединение, заново выполняли PRAGMA и закрывали соединение. В 2.2 используется небольшой пул постоянных соединений с WAL.

```env
DB_POOL_SIZE=4
```

Все существующие методы `Database` продолжают работать через `async with db.connection()`, но получают соединение из пула. Незавершённая транзакция перед возвратом соединения автоматически откатывается, чтобы не загрязнять следующий запрос.

### Раздельные AI-лимиты

Распознавание аниме и AI-поддержка больше не используют один общий semaphore. Поэтому всплеск вопросов в support не может занять все слоты поиска аниме.

```env
AIAI_MAX_CONCURRENCY=3
SUPPORT_AI_MAX_CONCURRENCY=1
```

### Метрики

`/health` теперь показывает:

- RAM процесса;
- число активных поисков;
- текущие и пиковые одновременно обрабатываемые сообщения;
- число отклонений rate-limit / overload;
- состояние SQLite pool.

## Исправление support

В vkbottle 4.11 shortcut `coro=` создаёт `CoroutineRule`, который вызывает coroutine-функцию без объекта сообщения. `SupportDesk.should_handle(message)` требует `Message`, поэтому это приводило к:

```text
TypeError: SupportDesk.should_handle() missing 1 required positional argument: 'message'
```

В 2.2 регистрация support-хендлера исправляется на `func=`, то есть `FuncRule`, который передаёт `Message` в `should_handle`.

## Поддержка

Команда `support`, `/support`, `поддержка` или deep-link с `ref=support` открывает поддержку.

Сначала пользователь выбирает тему:

- **Техническая проблема** — сразу живому администратору
- **Оплата** — сразу живому администратору
- **Поиск и режимы** — AI-поддержка
- **Аккаунт и запросы** — AI-поддержка
- **Бонусы и рефералы** — AI-поддержка
- **Функции AniKot** — AI-поддержка
- **Другое** — AI-поддержка

AI первой линии по умолчанию использует `qwen3-32b`. Если вопрос относится к оплате, технической неисправности или AI не знает точного ответа, он передаётся оператору.

```env
SUPPORT_ADMIN_IDS=
SUPPORT_AI_MODEL=qwen3-32b
SUPPORT_AI_MAX_TOKENS=700
SUPPORT_AI_TIMEOUT=90
SUPPORT_AI_HISTORY_LIMIT=6
SUPPORT_AI_HOURLY_LIMIT=20
SUPPORT_AI_MAX_CONCURRENCY=1
```

После нажатия оператором `Ответить` его обычные сообщения отправляются только выбранному пользователю. После ответа бот показывает `Ожидать ответ | Закрыть чат`.

## Интерфейс поиска

Во время поиска показывается временное сообщение:

```text
🔍 AniKot анализирует кадр...
```

Кнопка отмены называется `Отмена`. После завершения поиска временное сообщение удаляется.

Формат результата:

```text
🎬 Название: Внук мудреца
👤 Персонаж: Сицилия фон Клод
🌍 Страна: Япония
📅 Год: 2019
📺 Количество эпизодов: 12
🎯 Уверенность: 95%
```

## Регистрация и бонусы

- регистрация: `+1` обычный AniKot;
- подписка на сообщество: `+2` обычных AniKot один раз;
- приглашённый друг: `+3` AniKot Pro после 3-дневной проверки;
- 3 страйка за отписку после получения бонуса блокируют аккаунт;
- явно не-аниме изображение не списывает поисковый запрос, но может дать предупреждение.
